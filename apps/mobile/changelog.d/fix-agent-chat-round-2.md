### Fixed

- In an agent chat, the keyboard now stays open after you send a message, so you can type the next one at once. Before, the keyboard closed after each send. The word that the keyboard still holds is sent with the message.
- In Android chats with ColorOS motion on, a sent message now moves in from the end side with a spring, on screen, while the list glides to it. Before, the message came in below the visible area, and the list jumped to it after a pause.
