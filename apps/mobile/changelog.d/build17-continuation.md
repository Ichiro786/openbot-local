- Application confirmations and error alerts on Android now share one dialog host. ColorOS uses the existing glass system where the focused screen supplies a blur target, with a solid fallback elsewhere. ColorOS off uses a native Material 3 dialog. Destructive actions use the danger text color. System permissions and iOS alerts stay native.
- The dialog queue preserves pending choices, button callbacks, cancelability and dismissal callbacks. Repeated taps and late animation callbacks cannot run an action twice. The app behind a dialog is hidden from accessibility services and does not receive touches. Opening a dialog dismisses the keyboard and closes any glass menu. Dialog frost pauses the background glass surfaces.
- Android ColorOS chats no longer reserve a screen of space beneath the latest sent message. They scroll to the actual end after the new row and keyboard settle. Reader drags, cancellation, settings changes and unmount cancel pending scroll work.
- ColorOS streaming message revisions are combined per animation frame. New and final replies remain immediate. Android bubble resizing springs and per-word fades remain disabled because the existing implementation records background lag and text flicker with them.
- Agent photos retain the generated avatar until the current image displays. Failed image loads keep that fallback; late events from a previous image source are ignored. The marketplace-specific import failure still needs reproduction on a phone.
- Fix the two nullable thermal-listener arguments that stopped the first Build 17 Kotlin compilation in PowerGovernor.
- Native engine and header changes require a new APK/runtime. These changes have not passed a native build or phone verification yet.
